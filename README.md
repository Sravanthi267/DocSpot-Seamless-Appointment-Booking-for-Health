#  DocSpot — Seamless Appointment Booking for Health

DocSpot is a responsive web-based doctor appointment booking application designed to make it easier for users to discover doctors, select a convenient appointment time, and manage their appointments through a simple and user-friendly interface.

> **Project Scope:** DocSpot is currently a frontend prototype. Authentication, doctor data, and appointment management are simulated using JavaScript and are not connected to a production backend or database.

##  Features

*  User Registration and Login
*  Browse available doctors
*  Search doctors by name or specialty
*  Filter doctors by medical specialty
*  Select appointment date and time
*  Select medical documents for an appointment
*  View booked appointments
*  Request appointment rescheduling
*  Cancel appointments
*  User-friendly notification messages
*  Loading indicators for simulated operations
*  Responsive design for different screen sizes
*  Modern UI with hover effects and smooth transitions

##  Technologies Used

* **HTML5** — Application structure
* **CSS3** — Custom styling and responsive design
* **Tailwind CSS** — UI styling and layout
* **JavaScript (ES6+)** — Application logic and interactions
* **Google Fonts** — Typography

## ⚙️ How It Works

### 1. Register / Login

Users can create an account and log in through the application's authentication interface.

### 2. Browse Doctors

After logging in, users can browse the available doctors and search or filter them based on specialty.

### 3. Book an Appointment

Users can select a doctor, choose a preferred date and time, and optionally select a medical document.

### 4. Manage Appointments

Users can view their appointments and request rescheduling or cancellation.

##  Running the Project Locally

1. Clone or download this repository.
2. Open the project folder.
3. Make sure the required background image is present in the same folder as `project.html`.
4. Open `project.html` in a modern web browser.
5. Use the Register option to create a demo account.
6. Log in and explore the appointment booking workflow.

No server setup is required for the current frontend prototype.

##  Current Implementation

The current version demonstrates the complete frontend user flow using JavaScript.

The application uses simulated operations for:

* User registration
* User authentication
* Doctor data retrieval
* Appointment booking
* Appointment rescheduling
* Appointment cancellation

User and appointment data are maintained in browser memory during the current session.
